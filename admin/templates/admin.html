Cấu hình API Server

Nhập URL API server đã deploy trên WinServer

Port API của MikroTik (mặc định: 3544)

info Cách hoạt động

  • URL này được lưu trên Firebase, tất cả user sẽ nhận được tự động
  • Khi user mở tab API, ứng dụng tự điền URL và kết nối
  • User chỉ cần tạo Token → nhận link xoay IP ngay
  • Nếu thay đổi server, chỉ cần sửa URL ở đây, không cần cập nhật app
