menu_book Tài liệu API — HT Proxy

API xoay IP hoạt động qua giao thức HTTP GET. Bạn chỉ cần dán link vào trình duyệt, gọi từ cURL, bot Telegram, script Python/JS hoặc bất kỳ phần mềm nào hỗ trợ HTTP request là có thể xoay IP proxy từ xa.

GET

Xoay IP một proxy cụ thể

pppoe-out{N} — tên interface PPPoE cần xoay. Thay {N} bằng số thứ tự interface (VD: pppoe-out2, pppoe-out3, ..., pppoe-out32).

Hệ thống sẽ disconnect → reconnect interface, chờ IP mới. Nếu IP mới trùng IP cũ, tự động thử lại tối đa 5 lần.

Response thành công

{
  "success": true,
  "host": "huynhty.proxydaphien.ltd",
  "interface": "pppoe-out2",
  "old_ip": "42.116.182.132",
  "new_ip": "42.113.213.34",
  "retries": 1,
  "elapsed_ms": 3842,
  "message": "Đã xoay IP thành công cho pppoe-out2 (sau 1 lần thử)"
}

Response thất bại

{
  "success": false,
  "host": "huynhty.proxydaphien.ltd",
  "interface": "pppoe-out2",
  "old_ip": "42.116.182.132",
  "new_ip": "42.116.182.132",
  "retries": 5,
  "elapsed_ms": 25410,
  "message": "Không thể xoay IP mới sau 5 lần thử (IP vẫn trùng)"
}

warning Lưu ý quan trọng


    

  • 1. pppoe-out1 là cổng quản trị router — không được xoay, hệ thống tự bỏ qua.
    • 

  • 2. Mỗi token có thể dùng cho nhiều router cùng lúc. Không cần tạo token riêng cho mỗi router.
    • 

  • 3. Hệ thống tự retry tối đa 5 lần nếu IP mới trùng IP cũ, mỗi lần chờ khoảng 3-5 giây.
    • 

  • 4. Token bị tắt (trạng thái Off) sẽ bị từ chối với HTTP 401. Bật lại trong tab Tokens.
    • 

  • 5. Mọi request đều được ghi log. Xem chi tiết trong tab Logs (thời gian, IP cũ/mới, kết quả).
    • 

  • 6. Nên chờ ít nhất 10 giây giữa 2 lần xoay cùng 1 interface để tránh conflict.
    •
